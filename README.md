# 📱 IMC Calculator — Calculadora de IMC

Aplicativo Android nativo desenvolvido em Kotlin, com o objetivo de calcular o Índice de Massa Corporal (IMC) e apresentar sua classificação.

Projeto desenvolvido durante meus estudos de desenvolvimento Android na Nova Era Tech School

## 📋 Sobre o aplicativo

O aplicativo permite que o usuário informe seu peso e sua altura para calcular automaticamente seu IMC.

O resultado é exibido em uma tela específica, acompanhado da classificação correspondente.

## ✨ Funcionalidades

Tela de abertura (Splash Screen).

Entrada de peso e altura.

Validação dos dados informados.

Cálculo automático do IMC.

Exibição do resultado com duas casas decimais.

Classificação em abaixo do peso, normal, sobrepeso ou obesidade.

Navegação entre as telas.

## 🛠️ Tecnologias utilizadas

Kotlin — linguagem de programação.

Android Studio — ambiente de desenvolvimento.

XML — construção das interfaces.

ConstraintLayout — organização dos elementos visuais.

Activities e Intents — navegação e transferência de dados.

Git e GitHub — versionamento de código.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei conceitos de programação orientada a objetos, manipulação de componentes de interface, validação de entradas, navegação entre Activities e passagem de informações utilizando Intents.

Também apliquei boas práticas de organização do código, como o uso de constantes para identificar os dados enviados entre telas.
